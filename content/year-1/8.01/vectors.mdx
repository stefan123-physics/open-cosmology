Physics needs two kinds of quantities. Some are fully described by a single number with units: a mass of 2 kg, a temperature of 300 K. These are **scalars**. Others also need a direction. A push of 10 newtons to the left is a different thing from a push of 10 newtons upward. Quantities like this are **vectors**. Position, displacement, velocity, acceleration, force and momentum are all vectors.

This first lesson is about the language of vectors. Almost everything that follows uses it, including, in the end, the motion of galaxies in an expanding universe.

## Vectors as arrows

We draw a vector $\vec A$ as an arrow. The arrow points in the vector's direction, and its length shows the vector's **magnitude**, written $|\vec A|$ or just $A$. Where the arrow is drawn does not matter. Two arrows with the same length and direction are the same vector, wherever they sit.

Vectors come with two operations.

**Addition.** To add $\vec B$ to $\vec A$, place the tail of $\vec B$ at the tip of $\vec A$. The sum $\vec C = \vec A + \vec B$ is the arrow from the tail of $\vec A$ to the tip of $\vec B$. You can also draw both arrows from the same point and complete the parallelogram; the diagonal is the same $\vec C$.

The order does not matter (adding is **commutative**), and when you add three vectors it does not matter which pair you add first (it is **associative**):

<Formula label="Rules of vector addition" tex="\vec A + \vec B = \vec B + \vec A, \qquad (\vec A + \vec B) + \vec C = \vec A + (\vec B + \vec C)" cite="reading1" at="Eqs. (3.1.1)–(3.1.2)" />

There is a zero vector $\vec 0$ that changes nothing when added, and every vector has an opposite, $-\vec A$: same length, reversed direction, so that $\vec A + (-\vec A) = \vec 0$. Subtracting a vector means adding its opposite.

**Multiplication by a number.** Multiplying $\vec A$ by a number $c$ stretches its length by $|c|$. If $c$ is positive the direction stays the same; if $c$ is negative the direction flips. Dividing a vector by its own magnitude leaves an arrow of length exactly 1 that points the same way. This is a **unit vector**, marked with a hat:

<Formula label="Unit vector" tex="\hat A = \frac{\vec A}{|\vec A|}, \qquad |\hat A| = 1" cite="reading1" at="Eq. (3.1.10)" />

## Coordinate systems

Arrows are good for intuition, but to calculate we need numbers. A **coordinate system** turns vectors into numbers. Setting one up takes four choices:

1. an **origin**, the point every position is measured from;
2. a set of **axes**;
3. a **positive direction** on each axis;
4. a set of **unit vectors** at every point.

These choices are ours to make. A good choice can turn a messy problem into an easy one, which is why it pays to draw the coordinate system before calculating anything.

**Cartesian coordinates** use three perpendicular axes $x$, $y$, $z$. At every point the unit vectors $\hat i$, $\hat j$, $\hat k$ point toward increasing $x$, $y$ and $z$. They point the same way everywhere, which makes Cartesian coordinates the simplest system to calculate in.

**Polar coordinates** describe a point in a plane by its distance $r$ from the origin and the angle $\theta$ from the $+x$ axis, measured counterclockwise. Adding a height $z$ gives **cylindrical coordinates**. The two descriptions are linked by

<Formula label="Polar ↔ Cartesian" tex="x = r\cos\theta,\quad y = r\sin\theta \qquad\Longleftrightarrow\qquad r = \sqrt{x^2 + y^2},\quad \theta = \tan^{-1}(y/x)" cite="reading1" at="Eqs. (3.2.2)–(3.2.5)" />

(The inverse tangent needs care about which quadrant the point is in; more on that below.) Polar coordinates also have their own unit vectors: $\hat r$ points straight away from the origin and $\hat\theta$ points around the circle, counterclockwise. Unlike $\hat i$ and $\hat j$, these change direction from point to point. That will matter when we study circular motion.

## Components

Once we have unit vectors, any vector can be split into pieces along the axes. The numbers in front of the unit vectors are the **components**:

<Formula label="A vector in components" tex="\vec A = A_x\,\hat i + A_y\,\hat j + A_z\,\hat k" cite="reading1" at="Eq. (3.3.4)" />

A component is a signed number: $A_x$ is negative if $\vec A$ points partly toward $-x$. So one vector in three dimensions is described by three numbers $(A_x, A_y, A_z)$.

**Magnitude.** By Pythagoras, the length of the arrow is

<Formula label="Magnitude" tex="A = |\vec A| = \sqrt{A_x^2 + A_y^2 + A_z^2}" cite="reading1" at="Eq. (3.3.5)" />

**Direction.** For a vector in the $xy$-plane that makes an angle $\theta$ with the $+x$ axis,

<Formula label="Components from magnitude and angle" tex="A_x = A\cos\theta, \qquad A_y = A\sin\theta, \qquad \tan\theta = \frac{A_y}{A_x}" cite="reading1" at="Eqs. (3.3.6)–(3.3.8)" />

<Callout kind="warning" title="The arctangent trap">
The arctangent only returns angles between $-90^\circ$ and $+90^\circ$, but a vector can point anywhere. The vector $(A_x, A_y) = (-2, 3)$ and the vector $(2, -3)$ give the same ratio $A_y/A_x$, yet point in opposite directions. Always check the signs of the components to decide which quadrant the vector is in, and add $180^\circ$ if needed.
</Callout>

## Adding vectors with components

Adding arrows head to tail is exactly the same as adding their components separately:

<Formula label="Addition by components" tex="\vec C = \vec A + \vec B \quad\Longleftrightarrow\quad C_x = A_x + B_x, \quad C_y = A_y + B_y" cite="reading1" at="Eq. (3.3.14)" />

That is the real reason components are useful. Adding arrows takes geometry; adding numbers takes arithmetic.

<WorkedExample title="Two displacements">
<Problem>
A rover drives 5.0 m in a direction $30^\circ$ above the $+x$ axis, then 3.0 m in a direction $120^\circ$ from the $+x$ axis. How far is it from where it started, and in which direction?
</Problem>
<Step title="Choose the coordinate system">
Put the origin at the start, $+x$ to the east and $+y$ to the north, with angles measured counterclockwise from $+x$. Call the two displacements $\vec A$ and $\vec B$.
</Step>
<Step title="Find the components of each vector">
$A_x = 5.0\cos 30^\circ = 4.33$ m, $A_y = 5.0\sin 30^\circ = 2.50$ m.

$B_x = 3.0\cos 120^\circ = -1.50$ m, $B_y = 3.0\sin 120^\circ = 2.60$ m.

$B_x$ is negative because the second leg points partly west.
</Step>
<Step title="Add component by component">
$C_x = 4.33 + (-1.50) = 2.83$ m and $C_y = 2.50 + 2.60 = 5.10$ m.
</Step>
<Step title="Convert back to magnitude and direction">
$C = \sqrt{2.83^2 + 5.10^2} = 5.83$ m. Both components are positive, so the vector is in the first quadrant and $\theta_C = \tan^{-1}(5.10/2.83) = 61.0^\circ$.
</Step>
<Step title="Check the answer another way">
The two legs differ in direction by exactly $90^\circ$, so they form a right triangle: $C = \sqrt{5.0^2 + 3.0^2} = 5.83$ m, and $C$ points $\tan^{-1}(3/5) = 31.0^\circ$ beyond the first leg, at $30^\circ + 31.0^\circ = 61.0^\circ$. The two methods agree.
</Step>
</WorkedExample>

<Callout kind="cosmology">
Building on Vesto Slipher's measurements of galaxy redshifts, Georges Lemaître (1927) and Edwin Hubble (1929) found that distant galaxies move away from us, and that a galaxy twice as far away moves away twice as fast. As vectors, this says each galaxy's velocity $\vec v$ is its position vector $\vec r$ multiplied by one number, the Hubble parameter $H$:

<Formula label="Hubble's law (as a vector equation)" tex="\vec v = H\,\vec r" cite="guth" />

Multiplying a vector by a positive number keeps its direction, so every galaxy moves straight away from us. In 8.286 you will see that the same law holds from the point of view of *any* galaxy. That is one reason there is no centre to the expansion.
</Callout>

## Summary

- A vector has a magnitude and a direction; it adds head to tail, and multiplying by a number stretches or flips it.
- A coordinate system needs an origin, axes, positive directions and unit vectors.
- In components, $\vec A = A_x\hat i + A_y\hat j + A_z\hat k$, with $A = \sqrt{A_x^2 + A_y^2 + A_z^2}$.
- Vectors add component by component. Watch the quadrant when you convert components back into an angle.
