The last lecture on the Laplace transform covers one more kind of input that other courses will expect you to know: the impulse (transcript, p. 1). It builds on [step functions and the t-axis translation formula](/courses/18-03/laplace-discontinuous-inputs).

## Unit impulses

For a force $f(t)$ acting along a line, physicists define the impulse over $[a, b]$ as $\int_a^bf(t)\,dt$; for a constant force $F$ it is just $F(b - a)$ (transcript, p. 1). Push the undamped spring–mass system with a constant force from time 0 to time $h$, say with an electromagnet. For a **unit** impulse the area must be 1, so the force is $\frac1h$: the narrower the box, the higher (p. 2). In terms of the unit step (pp. 2–4):

<Formula label="Unit impulse over [0, h]" tex="\frac{1}{h}\,u_{0h}(t) = \frac{1}{h}\big(u(t) - u(t - h)\big), \qquad \mathcal{L}\left(\frac{1}{h}\,u_{0h}(t)\right) = \frac{1 - e^{-hs}}{hs}" cite="reading1" at="pp. 3–4" />

using $\mathcal{L}(u) = \frac1s$ and the t-axis translation formula (pp. 3–4).

## The delta function

Now let $h \to 0$ (transcript, p. 4). With $v = hs$ and L'Hôpital's rule, $\lim_{v \to 0}\frac{1 - e^{-v}}{v} = \lim_{v \to 0}e^{-v} = 1$ (pp. 4–5). Meanwhile the boxes become zero everywhere except at 0, where they are infinitely high (p. 5). That limit is not a function; mathematicians call it a generalized function. The physicist Dirac introduced it formally and, as such people do, named it with his own initial: the **delta function** $\delta(t)$ (pp. 5–6). From here on everything is in figurative quotation marks: it is declared to have the properties the limit suggests (p. 6):

<Formula label="Delta function" tex="\mathcal{L}(\delta(t)) = 1, \qquad \int_{-\infty}^{\infty}\delta(t)\,dt = 1" cite="reading1" at="p. 6" />

the second saying that it is a unit impulse (p. 6).

**Identity for convolution** (p. 7). Assuming it obeys the laws of the transform, $\mathcal{L}(f * \delta) = F(s)\cdot 1 = F(s)$, so with $f$ made zero for $t < 0$,

<Formula label="Convolution with δ" tex="f(t) * \delta(t) = f(t)" cite="reading1" at="p. 7" />

Convolution is commutative and linear, much like multiplication, and $\delta$ is its identity element (p. 7). One more property, by an equally loose argument: the unit step has derivative 0 except at 0, where it goes straight up, so $u'(t) = \delta(t)$; in solving equations it behaves as if that were true (p. 8).

## Kicking the spring

The undamped spring starts at rest at position 1 and is kicked with impulse $A$ at time $\frac{\pi}{2}$, just as it passes equilibrium (transcript, pp. 8–9):

<Formula label="A kicked spring" tex="y'' + y = A\,\delta\!\left(t - \frac{\pi}{2}\right), \qquad y(0) = 1, \quad y'(0) = 0" cite="reading1" at="p. 9" />

Transforming, with the translation formula on the right (pp. 9–10): $s^2Y - s + Y = Ae^{-\pi s/2}$, so $Y = \frac{s}{s^2 + 1} + \frac{Ae^{-\pi s/2}}{s^2 + 1}$. Inverting (p. 10):

<Formula label="Solution" tex="y = \cos t + u\!\left(t - \frac{\pi}{2}\right)A\sin\!\left(t - \frac{\pi}{2}\right)" cite="reading1" at="p. 10" />

In cases form, since $\sin(t - \frac{\pi}{2}) = -\cos t$ (p. 11):

<Formula label="Solution in cases" tex="y = \begin{cases} \cos t, & 0 \le t < \pi/2 \\ (1 - A)\cos t, & t \ge \pi/2 \end{cases}" cite="reading1" at="p. 11" />

The two pieces agree at $\frac{\pi}{2}$, where both are 0: the solution is continuous but not differentiable there (p. 11). If $A > 1$ the mass reverses direction; if $A < 1$ it carries on, with a smaller amplitude; and if $A = 1$ it stops dead (pp. 11–12). The lecture demonstrated this with a pendulum and a student with a bat; a colleague with a mallet could stop it dead every time (pp. 12–14).

## Transfer function and weight function

Some engineering vocabulary, used by everyone who uses the transform (transcript, p. 14). For a system $y'' + ay' + by = f(t)$ starting at rest, $y(0) = y'(0) = 0$ (pp. 14–15), the transform gives $s^2Y + asY + bY = F(s)$, so

<Formula label="Transfer function" tex="Y = F(s)\,W(s), \qquad W(s) = \frac{1}{s^2 + as + b}" cite="reading1" at="p. 15" />

$W(s)$ depends only on the system (the damping and spring constants), not on the input: the **transfer function** (p. 15). Its inverse transform $w(t)$ is the **weight function**, and by the convolution formula (pp. 15–16)

<Formula label="Solution as a convolution" tex="y(t) = f(t) * w(t) = \int_0^{t}f(u)\,w(t - u)\,du" cite="reading1" at="pp. 15–16" />

The solution for any input is a definite integral (p. 16). What is $w$? Feed in a kick, $f = \delta(t)$: then $Y = W(s)$, so **the weight function is the response of the system at rest to a unit impulse at time 0** (pp. 16–17). The notes explain the solution as a superposition of many such kicks (p. 17).

<WorkedExample title="Weight functions and a kick">
<Problem>
(a) Find the weight function of $y'' + 4y = f(t)$. (b) For $y'' + 3y' + 2y = f(t)$ at rest, find $w(t)$ and use it to find the response to $f = 1$. (c) The spring of the lecture starts instead at $y(0) = 2$. What impulse at $t = \frac{\pi}{2}$ stops it?
</Problem>
<Step title="(a) An undamped spring">
$W(s) = \frac{1}{s^2 + 4}$, so $w(t) = \frac{1}{2}\sin 2t$: a kick sets it oscillating.
</Step>
<Step title="(b) A damped system">
$W(s) = \frac{1}{(s + 1)(s + 2)} = \frac{1}{s + 1} - \frac{1}{s + 2}$, so $w = e^{-t} - e^{-2t}$. Then $y = 1 * w = \int_0^t(e^{-u} - e^{-2u})\,du = \frac{1}{2} - e^{-t} + \frac{1}{2}e^{-2t}$, which tends to the steady state $\frac{1}{2}$.
</Step>
<Step title="(c) Stopping it">
Now $y = 2\cos t$ until $\frac{\pi}{2}$, where the velocity is $-2$, and $(2 - A)\cos t$ afterwards. So $A = 2$ stops it: the impulse must cancel the momentum, here with unit mass.
</Step>
</WorkedExample>

## Summary

- A unit impulse is a force of total integral 1; the box $\frac{1}{h}(u(t) - u(t - h))$ has transform $\frac{1 - e^{-hs}}{hs} \to 1$.
- The delta function: $\mathcal{L}(\delta) = 1$, $\int\delta = 1$, $f * \delta = f$, and formally $u' = \delta$.
- A kick $A\delta(t - a)$ enters the transform as $Ae^{-as}$; the kicked spring stops when the impulse cancels its momentum.
- Transfer function $W(s) = \frac{1}{s^2 + as + b}$; weight function $w$ = response to a unit kick; $y = f * w$.
