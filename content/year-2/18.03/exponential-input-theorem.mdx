With [the structure of the solutions](/courses/18-03/inhomogeneous-equations-and-stability) settled, all the work lies in finding one particular solution $y_p$; this lecture and the next do it for the most important inputs (transcript, p. 1).

## Exponential inputs

Not all right-hand sides are equally interesting (transcript, p. 1). The important ones are $e^{ax}$ (usually decaying, $a < 0$), the pure oscillations $\cos\omega x$ and $\sin\omega x$ (alternating current, or a spring shaken at a fixed frequency), and decaying oscillations $e^{ax}\cos\omega x$, $e^{ax}\sin\omega x$ (pp. 1–2). Later, arbitrary functions are built from these (p. 1). All are real or imaginary parts of one complex exponential (p. 2):

<Formula label="One complex exponential" tex="e^{\alpha x}, \qquad \alpha = a + i\omega" cite="reading1" at="p. 2" />

$\omega = 0$ gives the real exponential, $a = 0$ the pure oscillations (p. 2).

Write the equation $y'' + Ay' + By = f(x)$ with the **polynomial operator** $p(D) = D^2 + AD + B$ (pp. 2–3):

<Formula label="Polynomial operator form" tex="p(D)\,y = f(x), \qquad p(D) = D^2 + AD + B" cite="reading1" at="p. 2" />

Almost everything below works for polynomials of higher degree too (pp. 2–3).

## The substitution rule

Applying $p(D)$ to an exponential just substitutes $\alpha$ for $D$ (transcript, p. 3):

<Formula label="Substitution rule" tex="p(D)\,e^{\alpha x} = p(\alpha)\,e^{\alpha x}" cite="reading1" at="p. 3" />

It is clear for $D$ and $D^2$, since $De^{\alpha x} = \alpha e^{\alpha x}$ and $D^2e^{\alpha x} = \alpha^2e^{\alpha x}$, and so by linearity for any $p(D)$: $(D^2 + AD + B)e^{\alpha x} = e^{\alpha x}(\alpha^2 + A\alpha + B)$ (pp. 3–4).

## The exponential input theorem

**Theorem** (pp. 4–5). If $p(\alpha) \ne 0$, a particular solution of $p(D)y = e^{\alpha x}$ is

<Formula label="Exponential input theorem" tex="y_p = \frac{e^{\alpha x}}{p(\alpha)}" cite="reading1" at="p. 4" />

Proof: $p(\alpha)$ is a constant and $p(D)$ is linear, so $p(D)\frac{e^{\alpha x}}{p(\alpha)} = \frac{p(\alpha)e^{\alpha x}}{p(\alpha)} = e^{\alpha x}$ (p. 5). Haynes Miller, who also teaches the course, calls it the most important theorem in it (p. 5). The case $p(\alpha) = 0$ is excluded for now; it is the case of resonance, behind all sorts of catastrophes and many good things too (pp. 5–6).

**Example** (pp. 6–9). Find a particular solution of

<Formula label="A decaying oscillation as input" tex="y'' - y' + 2y = 10\,e^{-x}\sin x" cite="reading1" at="p. 6" />

(The transcript reads the middle term as "plus minus $y'$".) The input is the imaginary part of $10\,e^{(-1 + i)x}$, so complexify: solve $\tilde y'' - \tilde y' + 2\tilde y = 10\,e^{(-1 + i)x}$ and take the imaginary part (pp. 6–7). With $\alpha = -1 + i$ (pp. 7–8),

<Formula label="Complex particular solution" tex="\tilde y_p = \frac{10\,e^{(-1 + i)x}}{(-1 + i)^2 - (-1 + i) + 2} = \frac{10\,e^{(-1 + i)x}}{3 - 3i} = \frac{5}{3}\,(1 + i)\,e^{-x}(\cos x + i\sin x)" cite="reading1" at="pp. 7–8" />

using $\frac{1}{1 - i} = \frac{1 + i}{2}$. Most of the work is making the result human enough to take its imaginary part (p. 8):

<Formula label="The real particular solution" tex="y_p = \frac{5}{3}\,e^{-x}(\cos x + \sin x) = \frac{5\sqrt2}{3}\,e^{-x}\cos\!\left(x - \frac{\pi}{4}\right)" cite="reading1" at="pp. 8–9" />

the second form from the [sine–cosine identity](/courses/18-03/sinusoids-and-linear-models), with a triangle of sides 1 and 1 (pp. 8–9).

## The exponential shift rule

To handle $p(\alpha) = 0$, a second rule is needed, for an exponential times another function $u(x)$ (transcript, p. 9). Renaming $\alpha$ as $a$, still allowed to be complex (p. 9):

<Formula label="Exponential shift rule" tex="p(D)\,(e^{ax}u) = e^{ax}\,p(D + a)\,u" cite="reading1" at="pp. 9–10" />

Passing $e^{ax}$ to the left of the operator, where it can do no harm, changes $D$ to $D + a$; this avoids differentiating products again and again (p. 10). **Proof** (pp. 10–12). For $p(D) = D$ it is the product rule: $D(e^{ax}u) = e^{ax}Du + ae^{ax}u = e^{ax}(D + a)u$. For $D^2$, do not start differentiating twice; bootstrap: $D^2(e^{ax}u) = D\left(e^{ax}(D + a)u\right) = e^{ax}(D + a)^2u$, applying the first case to the function $(D + a)u$. By induction it holds for every power of $D$, and by linearity for every $p(D)$ (pp. 11–12).

## When p(a) = 0

For the input $e^{ax}$ with $p(a) = 0$ (pp. 13–14):

<Formula label="Exponential input theorem, resonant cases" tex="y_p = \frac{x\,e^{ax}}{p'(a)} \;\; \text{if } a \text{ is a simple root}, \qquad y_p = \frac{x^2e^{ax}}{p''(a)} \;\; \text{if } a \text{ is a double root}" cite="reading1" at="pp. 13–14" />

A quadratic has at most a double root; for higher degree the pattern continues with higher powers of $x$ and a factorial (p. 14).

**Proof for a simple root** (pp. 14–16). Then $p(D) = (D - a)(D - b)$ with $b \ne a$, and $p'(D) = (D - b) + (D - a)$, so $p'(a) = a - b \ne 0$; a simple root guarantees this (pp. 14–15). (The transcript says $b \ne A$ at this point; it means the root $a$.) By the shift rule, with the exponential written on the left (pp. 15–16),

<Formula label="The simple-root proof" tex="p(D)\,\frac{e^{ax}x}{p'(a)} = \frac{e^{ax}\,p(D + a)\,x}{a - b} = \frac{e^{ax}\,(D + a - b)\,D\,x}{a - b} = \frac{e^{ax}\,(a - b)}{a - b} = e^{ax}" cite="reading1" at="pp. 15–16" />

since $Dx = 1$ and $D1 = 0$ (p. 16). The double-root case is left as an exercise (p. 16).

**Example** (pp. 16–17). For $y'' - 3y' + 2y = e^x$, $p(1) = 1 - 3 + 2 = 0$, and 1 is a simple root (a double root would mean $p(D) = (D - 1)^2$). With $p'(D) = 2D - 3$, $p'(1) = -1$ (p. 17):

<Formula label="Simple-root example" tex="y_p = \frac{x\,e^x}{p'(1)} = -x\,e^x" cite="reading1" at="p. 17" />

<WorkedExample title="Four inputs">
<Problem>
Find a particular solution of (a) $y'' + 4y = e^{-x}$; (b) $y'' + 2y' + 2y = \cos 2x$; (c) $y'' - 4y = e^{2x}$; (d) $y'' - 6y' + 9y = e^{3x}$.
</Problem>
<Step title="(a) A real exponential">
$p(D) = D^2 + 4$, $p(-1) = 5$, so $y_p = \frac15 e^{-x}$.
</Step>
<Step title="(b) A sinusoid">
$\cos 2x = \mathrm{Re}\,e^{2ix}$ and $p(2i) = -4 + 4i + 2 = -2 + 4i$. Then $\frac{1}{-2 + 4i} = \frac{-2 - 4i}{20}$, and the real part of $\frac{-2 - 4i}{20}(\cos 2x + i\sin 2x)$ is $y_p = \frac{1}{10}(-\cos 2x + 2\sin 2x)$, an oscillation of amplitude $\frac{\sqrt5}{10} \approx 0.224$.
</Step>
<Step title="(c) A simple root">
$p(2) = 0$, $p'(D) = 2D$ and $p'(2) = 4$, so $y_p = \frac14 xe^{2x}$.
</Step>
<Step title="(d) A double root">
$p(D) = (D - 3)^2$, so 3 is a double root and $p''(3) = 2$: $y_p = \frac12 x^2e^{3x}$.
</Step>
</WorkedExample>

## Summary

- Exponentials, sinusoids and decaying oscillations are all (parts of) $e^{\alpha x}$ with complex $\alpha$.
- Substitution rule: $p(D)e^{\alpha x} = p(\alpha)e^{\alpha x}$; hence $y_p = e^{\alpha x}/p(\alpha)$ when $p(\alpha) \ne 0$.
- Exponential shift rule: $p(D)(e^{ax}u) = e^{ax}p(D + a)u$.
- If $p(a) = 0$: $y_p = xe^{ax}/p'(a)$ for a simple root, $x^2e^{ax}/p''(a)$ for a double root.
