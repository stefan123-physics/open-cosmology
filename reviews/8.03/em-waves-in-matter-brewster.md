## Arithmetic and answer checks
- Projections (notes p. 6 figure): $\hat k_I = (\sin\theta_I, \cos\theta_I)$ in $(x, z)$, $\vec E_{0I}$ along $(\cos\theta_I, -\sin\theta_I)$; $\vec E_{0R}$ along $(\cos\theta_I, \sin\theta_I)$; $\vec E_{0T}$ along $(\cos\theta_T, -\sin\theta_T)$. The $z$ components give $\varepsilon_1(-E_{0I}\sin\theta_I + E_{0R}\sin\theta_I) = -\varepsilon_2E_{0T}\sin\theta_T$ and the $x$ components give $E_{0I}\cos\theta_I + E_{0R}\cos\theta_I = E_{0T}\cos\theta_T$. Both match the page and notes p. 6.
- Dividing (i) by $-\varepsilon_1\sin\theta_I$ gives $E_{0I} - E_{0R} = \frac{\varepsilon_2\sin\theta_T}{\varepsilon_1\sin\theta_I}E_{0T} = \frac{\varepsilon_2 n_1}{\varepsilon_1 n_2}E_{0T}$. The notes print $\sin\theta_I/\sin\theta_2$, which is inverted. The page's bracketed correction (sin θ_T/sin θ_I meant) is right. The transcript (p. 16) says "epsilon2 sine theta T divided by epsilon1 sine theta R", which is correct apart from the subscript.
- Solving $E_{0I} - E_{0R} = \beta E_{0T}$, $E_{0I} + E_{0R} = \alpha E_{0T}$ gives $E_{0T} = 2E_{0I}/(\alpha+\beta)$ and $E_{0R} = (\alpha-\beta)E_{0I}/(\alpha+\beta)$. Correct.
- Normal incidence: $\beta = (n_2^2/n_1^2)(n_1/n_2) = n_2/n_1$; $R = (1-\beta)/(1+\beta) = (n_1-n_2)/(n_1+n_2)$; $T = 2/(1+\beta) = 2n_1/(n_1+n_2)$. Correct.
- Grazing: $\cos\theta_I \to 0$, so $\alpha \to \infty$, $R \to 1$, $T \to 0$. Correct.
- Brewster: $\alpha = \beta$ gives $\cos\theta_T/\cos\theta_B = n_2/n_1 = \sin\theta_B/\sin\theta_T$, so $\sin 2\theta_T = \sin 2\theta_B$, so $\theta_B + \theta_T = \pi/2$ (the other root, $\theta_B = \theta_T$, needs $n_1 = n_2$). Then $n_1\sin\theta_B = n_2\cos\theta_B$, so $\tan\theta_B = n_2/n_1$. Correct. The tangent form is the page's own step and is labelled as such.
- Worked example: $\arctan 1.50 = 56.31°$; $90° - 56.31° = 33.69°$; $\sin 56.31° = 0.8321$ and $1.50\sin 33.7° = 0.8323$, both 0.832. $\arctan 1.33 = 53.06° \approx 53.1°$; $90° - 53.1° = 36.9° \approx 37°$ below the horizontal (the incidence angle is measured from the vertical normal), correct. $(1-1.50)/(1+1.50) = -0.20$ and $0.20^2 = 0.04$. The intensity ratio is $R^2$ because both waves are in the same medium. Correct.
- `npm run calc:test -- -k em-waves-in-matter`: 13 passed. The calcs file does not check $T = 2n_1/(n_1+n_2)$; you could add it (I verified it by hand above).
- Quiz 1 (answer 1), quiz 2 (answer 1, $v = 1/\sqrt{\mu\varepsilon} = c/n$), quiz 3 (answer 2, none: $\alpha = \beta$ gives $E_{0R} = 0$) and quiz 4 (answer 2: the angle between the reflected and transmitted rays is $180° - \theta_B - \theta_T = 90°$) are all correct, and so are their explanations. For quiz 1, see finding #2.
- Flashcards are correct. The $\tan\theta_B = n_2/n_1$ card assumes $\mu \approx \mu_0$, as the page does.
