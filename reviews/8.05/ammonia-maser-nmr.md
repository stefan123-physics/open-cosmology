## Arithmetic and answer checks
Recomputed by hand and in Python:
- $\nu = 0.9872\times10^{-4}\ \text{eV}/(4.135667\times10^{-15}\ \text{eV s}) = 2.38705\times10^{10}$ Hz = 23.870 GHz; $\lambda = c/\nu = 1.25594$ cm = 1.2559 cm. Correct.
- Time evolution: $\uparrow = (G + E)/\sqrt2$; evolving with $E_0 \mp \Delta$ and re-expanding gives coefficient $(e^{i\Delta t/\hbar} + e^{-i\Delta t/\hbar})/2 = \cos(\Delta t/\hbar)$ on up and $(e^{i\Delta t/\hbar} - e^{-i\Delta t/\hbar})/2 = i\sin(\Delta t/\hbar)$ on down. Correct. $P_\uparrow = \cos^2(\Delta t/\hbar) = \tfrac12(1 + \cos(2\Delta t/\hbar))$, so the probability oscillates at $2\Delta/\hbar = \omega_0$: the factor-2 remark (precession at $2\Delta/\hbar$ because spin states carry half the angle) is right, and "23 billion times a second" matches $\nu$.
- Energies in a field: $|\vec g| = \sqrt{\Delta^2 + \mu^2F^2}$; $\sqrt{\Delta^2 + v^2} = \Delta + v^2/2\Delta + O(v^4)$. Correct.
- Slow amplitudes (with $E_0 = 0$): $i\hbar\dot C_E = \Delta C_E + \mu F C_G$; substituting $C_E = e^{-i\Delta t/\hbar}\beta_E$, $C_G = e^{i\Delta t/\hbar}\beta_G$ gives $i\hbar\dot\beta_E = \mu F e^{i\omega_0t}\beta_G$ with $\omega_0 = 2\Delta/\hbar$; with $F = F_0(e^{i\omega_0t} + e^{-i\omega_0t})$ this is $\mu F_0(1 + e^{2i\omega_0t})\beta_G$. Correct. Dropping the fast term, $\ddot\beta_E = -(\mu F_0/\hbar)^2\beta_E$; with $\beta_E(0) = 1$, $\dot\beta_E(0) = -i(\mu F_0/\hbar)\beta_G(0) = 0$: $\beta_E = \cos(\mu F_0t/\hbar)$, $P_E = |C_E|^2 = |\beta_E|^2 = \cos^2$. Correct.
- Rotating frame: $i\hbar\,\partial_t(U\psi) = i\hbar\dot U U^\dagger\psi_R + UH_SU^\dagger\psi_R$; for $U = e^{-i\omega tS_z/\hbar}$, $i\hbar\dot UU^\dagger = \omega S_z$. Correct. The NMR field $B_1(\cos\omega t\,\hat x - \sin\omega t\,\hat y)$ starts on $+x$ and moves to $-y$: clockwise seen from $+z$. Correct.
- Worked example (a): $\sqrt{4.936^2 + 1} = 5.03628$; rise $= 1.003\times10^{-6}$ eV (page "≈ 1.00"); approximation $10^{-10}/9.872\times10^{-5} = 1.0130\times10^{-6}$ eV (page "≈ 1.01"); difference 1.0% ("within about 1%"); $1/4.936 = 0.203$ ("a fifth"). All correct.

Doubling $T$ gives phase $\pi$, $\cos^2 = 1$: back in the excited state, as stated. (Plausibility, not a finding: with ammonia's dipole of about 1.5 D, $\mu F_0 = 10^{-11}$ eV is a field of about 0.3 V/m and $\mu F = 10^{-5}$ eV about 3 kV/cm, both sensible.) The example is original; neither source has numbers for the Stark shift or the cavity.
