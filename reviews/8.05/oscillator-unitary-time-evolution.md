## Arithmetic and answer checks
Recomputed by hand:
- Factorisation: $(x - ip/m\omega)(x + ip/m\omega) = x^2 + p^2/m^2\omega^2 + (i/m\omega)[x, p] = x^2 + p^2/m^2\omega^2 - \hbar/m\omega$, so $\frac{1}{2}m\omega^2V^\dagger V = H - \frac{1}{2}\hbar\omega$. Correct.
- Ground state: $a \propto x + ip/m\omega$ with $p = (\hbar/i)\,d/dx$ gives $x + (\hbar/m\omega)\,d/dx$; $\psi_0 = N_0e^{-m\omega x^2/2\hbar}$ gives $\psi_0' = -(m\omega x/\hbar)\psi_0$, so the operator gives $0$. Correct.
- Ladder: $2.5 - 3 = -0.5$, correct; the following norm is $-0.5$ times a positive number, correct.
- Example (a): $\hat x^2 = \frac{\hbar}{2m\omega}(a^2 + a^{\dagger 2} + aa^\dagger + a^\dagger a)$, in $\psi_1$: $a^\dagger a \to 1$, $aa^\dagger \to 2$, so $(\Delta x)^2 = 3\hbar/2m\omega$ (with $\langle x\rangle = 0$). $\hat p^2 = -\frac{m\omega\hbar}{2}(a^{\dagger 2} + a^2 - a^\dagger a - aa^\dagger)$, so $(\Delta p)^2 = 3m\omega\hbar/2$ (the page does not state $\langle p\rangle = 0$, which is needed; same reason as for $x$; info). Product $3\hbar/2 = 3 \times \hbar/2$. All agree with notes (1.58)–(1.59) at $n = 1$.
- Example (b): $\partial U/\partial t\,U^\dagger = \mathrm{diag}(-i\omega_1, -i\omega_2)$, times $i\hbar$ gives $\mathrm{diag}(\hbar\omega_1, \hbar\omega_2)$. Correct; $\Lambda$ is anti-Hermitian as required.
