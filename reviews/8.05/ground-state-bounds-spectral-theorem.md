## Arithmetic and answer checks
Recomputed by hand and with NumPy/SciPy:
- Minimisation of $A/x^2 + Bx^4$: with $y = x^2$, $-A/y^2 + 2By = 0$ gives $y = 2^{-1/3}(A/B)^{1/3}$ and $f = \tfrac32 A/y = 2^{1/3}\tfrac32A^{2/3}B^{1/3}$. Correct.
- $A = \hbar^2/8m$, $B = \alpha$: $(1/8)^{2/3} = 1/4$, so $2^{1/3}\cdot\tfrac32\cdot\tfrac14 = 2^{1/3}\cdot\tfrac38 = 0.47247$. Correct (0.4724).
- Exact quartic value: finite-difference diagonalisation of $p^2/2 + x^4$ ($\hbar = m = \alpha = 1$) gives $0.66799$. Confirms 0.668.
- Worked example (a): $\langle x^8\rangle \ge \langle x^4\rangle^2 \ge \langle x^2\rangle^4$ is valid (both sides non-negative). $f = a/X + \gamma X^4$, $f' = 0$ at $X^5 = a/4\gamma$, then $\gamma X^4 = a/4X$ and $f_{\min} = \tfrac54 a/X = \tfrac54\,4^{1/5}a^{4/5}\gamma^{1/5}$. With $a = \hbar^2/8m$: $4^{1/5}/8^{4/5} = 2^{2/5-12/5} = 1/4$, giving $\tfrac{5}{16}(\hbar^8\gamma/m^4)^{1/5}$, 0.3125. Correct. Sanity check: numerical ground state of $p^2/2 + x^8$ is $0.7040$, above the bound, as it must be. The example is original (the lecture only mentions $x^8$ in passing, p. 9; neither source computes it).
- Worked example (b): $N^\dagger = \begin{pmatrix}1&-1\\1&1\end{pmatrix}$; $N^\dagger N = NN^\dagger = 2I$ (checked). $N(1, i) = (1+i, -1+i) = (1+i)(1, i)$; $N(1, -i) = (1-i, -1-i) = (1-i)(1, -i)$. Inner product $\overline{1}\cdot1 + \overline{i}\cdot(-i) = 1 + (-i)(-i) = 0$. NumPy eigenvalues $1 \pm i$ with eigenvectors $(1, \pm i)/\sqrt2$. Correct.
