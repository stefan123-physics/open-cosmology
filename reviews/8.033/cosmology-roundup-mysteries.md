## Arithmetic and answer checks
- Formula 1 (slide 57): I checked every value against the rendered table: Ω_tot $1.003^{+0.010}_{-0.009}$, Ω_Λ $0.761^{+0.017}_{-0.018}$, ω_b $0.0222 \pm 0.0007$, ω_c $0.1050^{+0.0041}_{-0.0040}$, w $-0.941^{+0.087}_{-0.101}$. All are correct. In the text, n_s = 0.953 ± 0.016 and r < 0.30 (95%) are also correct.
- Formula 2 (slide 63): "Ω_tot = 1.003 ± 0.010" is on slide 63 and repeated on slide 64. The citation is correct. Slide 63 credits "MT et al 2006, astro-ph/0608632", so "Tegmark and colleagues, 2006" is right.
- Worked example (a): 0.73² = 0.5329 → 0.533. 0.0222/0.5329 = 0.0417 → 0.042. 0.105/0.5329 = 0.1970 → 0.197. The sum is 0.2387 → 0.239, and 0.239 + 0.761 = 0.9997 → 1.000. All correct. The percentages 4 / 20 / 76 are consistent with these.
- Worked example (b): c/H₀ = 299 792/73 = 4107 Mpc ≈ 4100. 4100/√0.01 = 41 000 Mpc, which is 10 times c/H₀. Correct. The formula R = (c/H₀)/√|Ω_tot − 1| is the standard curvature radius (|Ω_k| = c²|k|/(a₀H₀)²). It is not on any slide, which is fine because it appears in the problem text and not as a cited Formula. The problem says "if |Ω_tot − 1| is below 0.01" as a hypothetical. The 1σ range on slide 63 actually allows values up to 0.013, so I would add the word "roughly" (info).
- Quiz 1 (answer 0, 75 / 21 / 4): correct per the slide 57 pie chart.
- Quiz 2 (answer 1, flat): correct. Slide 63 is titled "Evidence #1 for inflation: Space is very flat".
- Quiz 3 (answer 2, dimmer than expected): correct physics. As noted in finding 1, the slides imply this but do not state it.
- Quiz 4 (answer 3, end of inflation): correct. Slide 66 has this wording and cites Linde, Scientific American 271(5), November 1994.
- Flashcards: the three mysteries match slides 11 and 67. The recipe card is correct. ω_b = Ω_b h², ω_c = Ω_c h², and "units that do not depend on H₀" is correct (ω ∝ ρ, because ρ_c ∝ H₀²).
- Calcs file `calcs/8.033/cosmology-roundup-mysteries.yaml`: I recomputed every formula entry and all of them match. The source fields cite slide 57 or 63 for h = 0.73 and c/H₀, which do not appear on those slides (see finding 4). The `smoothness` entry cites slide 19 (see finding 2).
- `calcs/values.yaml` additions for this page: Ω_Λ 0.761 and n_s 0.953 match slide 57, and the role "historical: WMAP3 + SDSS LRGs (2006)" is correct. h = 0.73 is not registered, because the `h0` patterns only match `h_0 =` or `h ≈`, so "h = 0.73" is not checked. That is not an error.
- `npm run content:check`: 0 errors. The only warning for this page is the missing review file, which this review now provides.
