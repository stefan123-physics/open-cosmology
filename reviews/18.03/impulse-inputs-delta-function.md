## Arithmetic and answer checks
- `npm run calc:test -- -k impulse-inputs`: 7 passed.
- Box transform: $\frac1h\left(\frac1s - \frac{e^{-hs}}{s}\right) = \frac{1 - e^{-hs}}{hs}$. Correct. Calcs check at $h = 0.5$, $s = 2$: $\int_0^{0.5}2e^{-2t}dt = 1 - e^{-1} = 0.632121$. Correct.
- Limit: L'Hôpital, $\frac{d}{dv}(1 - e^{-v}) = e^{-v} \to 1$, denominator derivative 1. Correct.
- $\mathcal{L}(f * \delta) = F\cdot 1$, so $f * \delta = f$ (for $f$ zero at $t < 0$). Correct, matches p. 7.
- Kicked spring: $\mathcal{L}(y'') = s^2Y - sy(0) - y'(0) = s^2Y - s$; $\mathcal{L}(A\delta(t - \pi/2)) = Ae^{-\pi s/2}$; $Y = \frac{s}{s^2 + 1} + \frac{Ae^{-\pi s/2}}{s^2 + 1}$; inverse $\cos t + u(t - \frac\pi2)A\sin(t - \frac\pi2)$. Correct. $\sin(t - \frac\pi2) = -\cos t$, so $(1 - A)\cos t$ for $t \ge \frac\pi2$. Correct. Velocity jump at $\frac\pi2$: before $-\sin\frac\pi2 = -1$, after $-(1 - A) = A - 1$, jump $A$ (unit mass). $A > 1$: velocity becomes positive, so the mass reverses; $A = 1$: stops. Correct.
- Plot: curves `cos(t)` then `0.5*cos(t)` ($A = 0.5$), `0` ($A = 1$), `-cos(t)` ($A = 2$) all equal $(1 - A)\cos t$ after $\pi/2$. Caption correct. Domain $[0, 7]$, range $[-1.2, 1.2]$ contain all curves. The graph is the page's own; the lecture draws sketches on the board. Label placement was not checked in a browser (`content:check` does that). Minor: the dashed $A = 1$ curve lies on the $t$-axis after $\pi/2$, which may make it hard to see if the axis line is drawn at $y = 0$ (info, not verified visually).
- Transfer function: $s^2Y + asY + bY = F$ gives $Y = F/(s^2 + as + b)$. Correct. Convolution form $\int_0^t f(u)w(t - u)\,du$ matches p. 16 ("input … times this magic function but flipped and translated by t").
- Worked example (a): $\mathcal{L}^{-1}\frac{1}{s^2 + 4} = \frac12\sin 2t$. Correct (calcs `ex-a` checks the ODE; it does not check $w(0) = 0$, $w'(0) = 1$ although its `where` names them; both are true by inspection).
- (b): $\frac{1}{(s + 1)(s + 2)} = \frac{1}{s + 1} - \frac{1}{s + 2}$ (numerator $(s + 2) - (s + 1) = 1$). $1 * w = \int_0^t(e^{-u} - e^{-2u})du = (1 - e^{-t}) - \frac12(1 - e^{-2t}) = \frac12 - e^{-t} + \frac12e^{-2t}$. Correct; at $t = 2$: 0.373823 (calcs). Limit $\frac12 = \frac1b$. Correct. The integral is written as $\int w(u)\,du$ rather than $\int f(u)w(t - u)\,du$; equal by commutativity (fine).
- (c): $y = 2\cos t$, velocity at $\frac\pi2$ is $-2$; afterwards $(2 - A)\cos t$; $A = 2$ stops it, impulse = minus the momentum with unit mass. Correct.
- Quiz 1: $\mathcal{L}(\delta(t - a)) = e^{-as}$, answer 0. Correct; distractors wrong.
- Quiz 2: $f * \delta = f$, answer 0. Correct.
- Quiz 3: weight function = response to $\delta(t)$ = $\mathcal{L}^{-1}\frac{1}{s^2 + as + b}$, answer 0. Correct; explanation correct.
