# Fonts for the generated icons and share image

Used only by `npm run icons` (scripts/make-icons.ts) so the share image is set in the site's own typefaces; the website itself loads its fonts with `next/font`.

- EB Garamond (Medium, SemiBold) — SIL Open Font License 1.1, see OFL-EBGaramond.txt
- Source Serif 4 (Regular) — SIL Open Font License 1.1, see OFL-SourceSerif4.txt

Static TTFs from Google Fonts (fonts.gstatic.com).
