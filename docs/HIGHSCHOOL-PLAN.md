# The High School: the plan

> **2026-11-20: combined into Open Cosmology.** This plan was written for a separate site (`raimonvibe/open-cosmology-highschool`). The High School is now part of Open Cosmology: year 0, under `/highschool`, with its own colours (docs/HIGHSCHOOL-THEME.md). Its lesson lists are in `content/year-0/hs-0` … `hs-8`. Where this plan talks about a separate site, a separate repository, links to opencosmology.eu that "need internet" or `sync:university`, read it as history: the links are now internal. **OpenStax may not be used** (AGENTS.md, Writing rules 10, and flag F-OS in §7): the OpenStax-based lessons were deleted and the sources in §2 and §4 are on hold until new sources are decided.

Drafted and approved 2026-11-18. Built so far: the site skeleton and homepage, with the nine blocks and their lesson lists (§6 step 2); Blocks 0, 1 and 2 written and reviewed, with their practice sets (2026-11-19).

**What this is.** A free pre-university physics course at roughly Dutch VWO level that takes a complete beginner to the point where the Open Cosmology university programme ([opencosmology.eu](https://opencosmology.eu)) starts: MIT 8.01 and 18.01. It was first a separate site; since 2026-11-20 it is part of Open Cosmology as year 0 (`/highschool`).

## 3. How a lesson is built

### 3.1 Every lesson has
- **"You need this first"** box at the top: links to the earlier lessons (frontmatter `prerequisites`), with the key idea from each in one line. A lesson only uses terms introduced in earlier lessons; `check-content` enforces that prerequisites point backwards.
- Plain text, formulas through `<Formula cite="…">` with symbol popups, worked examples (`<WorkedExample>`) whose numbers are checked in `calcs/hs-N/<slug>.yaml`.
- A quiz (4–6 questions) and flashcards; read-aloud; PhET where it fits (listed below); full accessibility as on Open Cosmology (headings, alt text, keyboard, screen reader, focus mode).
- **"Where this leads"** at the end: links to the matching university lessons on `https://opencosmology.eu/courses/<course>/<slug>` (shown with the offline note, §1.3). All links in §4 were checked against the current Open Cosmology repository on 2026-11-18.
- **"Sources"** box: book, chapter, section and link; NASA page titles.

### 3.2 Citation format (replaces MIT lecture/slides/notes)
Frontmatter `source` becomes a list of book sections:

```yaml
sources:
  - book: college-physics-2e      # key into data/books.json (title, authors, licence, attribution)
    section: "2.5"                # chapter is derived: Chapter 2
    title: "Motion Equations for Constant Acceleration in One Dimension"
    url: https://openstax.org/books/college-physics-2e/pages/2-5-motion-equations-for-constant-acceleration-in-one-dimension
  - book: physics
    section: "3.2"
    title: "Representing Acceleration with Equations and Graphs"
    url: https://openstax.org/books/physics/pages/3-2-representing-acceleration-with-equations-and-graphs
nasa:
  - title: "Dark Matter - NASA Science"
    url: https://science.nasa.gov/dark-matter/
```

`<Formula cite="cp-2.5">` then points at a cited section (key = book short key + section; `nasa-1` for NASA pages). The `lecture` field becomes the lesson number (e.g. 1.6), `leadsTo` becomes a list of `{ course, slug, why }` on opencosmology.eu.

### 3.3 Practice sets
After a block's lessons are reviewed, one practice set per block (`kind: problems`, `solutions: own`), built with the existing `<Exercise>`, `<Part>`, `<Hint>`, `<Solution>` and `<Answer>` components: 8–12 problems covering the block, numbers checked in calcs, reviewed with the blind-solve step (§5.2). Problems are our own, modelled on the types in the cited "Problems & Exercises" sections.

### 3.4 Symbols
One High School glossary page (`/symbols`) with all meanings; the "used in" lists load on demand from `/symbols-usage.json`, as Open Cosmology does since it hit Vercel's 20 MB page limit. At ~110 lessons the page should stay far below that (Open Cosmology's single page reached 20 MB at ~400 lessons *with* the lists inlined). The build prints the page size; if it passes 10 MB we split into one page per block.

### 3.5 PhET
Sims are hosted locally (unmodified, pinned versions, `public/phet/manifest.json`) so they work offline. Each sim is 2.5–5 MB; every sim named below exists as an HTML5 sim (checked 2026-11-18). About 30 sims ≈ 100 MB of static files, which Vercel allows (the 20 MB limit is per page/function output, not total), but it lengthens the build and the offline download — see flag F7.

## 5. Checks and reviews

### 5.1 Automatic checks (`npm run content:check`, pre-commit hook, GitHub Actions on every pull request)
Same as Open Cosmology, with these changes:
- The rule "never OpenStax/LibreTexts" is removed. LibreTexts stays forbidden.
- Every lesson has at least one `sources` entry with a known `book` key, a section number that exists in that book's contents (stored in `data/books.json`, taken from openstax.org), and a URL on `openstax.org/books/<book>/pages/`. NASA entries need a title and a `nasa.gov` URL.
- Every `<Formula cite>` points at a cited section.
- `prerequisites` only point to earlier lessons; every lesson except 0.1 has at least one.
- `leadsTo` entries are well-formed opencosmology.eu paths. A weekly scheduled workflow (not on every PR, to avoid flaky builds) fetches them and reports broken links.
- Every block's last lesson is a "Towards the universe" lesson.
- calcs: every page with numbers has `calcs/hs-N/<slug>.yaml`; `npm run calc:test` runs in CI.
- `status: reviewed` requires `reviews/hs-N/<slug>.md` with verdict `pass` or `pass-with-notes`.
- Build prints the size of the largest page (glossary limit, §3.4).

### 5.2 The OpenStax/NASA reviewer
`.claude/agents/mit-lecture-reviewer.md` becomes `.claude/agents/openstax-nasa-reviewer.md`: an independent agent that did not write the page and reads the cited OpenStax sections (from openstax.org) and NASA pages, then checks **every formula, every number, every citation and every quiz answer** against the source:
- formulas: same physics, conventions noted where the site differs from the book;
- numbers: every worked example recomputed (and present in calcs); constants and astronomical values match the source or a newer NASA figure, with the date;
- citations: book, chapter, section number and title match the book's contents; the cited section really supports the claim;
- quiz and flashcards: the marked answer is right and the explanation is true;
- prerequisites: no term used before the lesson that introduces it;
- licensing: no copied sentences, no copied figures, correct attribution;
- "Where this leads" links point to a university lesson on the same topic.
It writes `reviews/hs-N/<slug>.md` (same template as Open Cosmology, "MIT says" → "Source says"). Practice sets get the blind-solve pass.
